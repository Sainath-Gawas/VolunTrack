# VolunTrack

A full-stack MERN web application designed to streamline community volunteering. VolunTrack empowers organizations to post opportunities, manage capacities and track community impact in real-time.

## ✨ Key Features

- **Dynamic Dashboard:** Real-time metrics calculation for active opportunities, pledged hours, and urgent requirements.
- **Smart Filtering:** Advanced search and filtering by activity type, date range, capacity, and urgency.
- **Pin-Secured CRUD:** Organizations can create, edit, and delete their listings secured by a custom 4-digit PIN authorization.
- **Flexible Capacity Logic:** Built-in logic to handle both fixed-hour/fixed-capacity events and flexible/unlimited community drives.
- **Responsive UI:** Clean, modern interface built with Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- MongoDB Atlas account (or local MongoDB)
